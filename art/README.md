# Editable original art

- `models/`: editable model source files.
- `textures/`: layered/source texture work.
- `animations/`: editable animation projects.
- `audio/`: original audio source work.

Export runtime-ready, licensed assets into `src/main/resources/assets/tentativerpg/` after namespace confirmation. Record creator, source, license/permission, edits and exported runtime paths in an attribution note alongside each asset set. Do not copy third-party mod art. Review large binary storage before committing source files.
